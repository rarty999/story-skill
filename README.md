## 🎯 核心升级(v7.1 → v8.0)

### 新增功能
1. ✨ **3种叙事类型自动判断**
   - Type A: 悬念-往事-爆发-收尾 (60-70%使用)
   - Type B: 平静-揭秘-真相-和解 (20-30%使用)
   - Type C: 冲突-压抑-爆发-独立 (10-20%使用)

   - 20条检查清单
   - 专门润色环节
   - 输出前统一处理

3. ✨ **系统化细节工具箱**
   - 50句老年人真实对话
   - 20个物品锚点
   - 30个日常动作细节

4. ✨ **量化节奏控制**
   - 每1000字的情绪密度配方
   - 必详写vs必简写规则
   - 3种类型各自的节奏规律

### 优化内容
- 文档精简36% (4389行 → 2800行)
- AI必读内容精简66% (需读1600行)
- 去除台湾化转换(保留台湾元素,简体输出)

## 🚀 使用方法

### 触发词
```
爆款老年故事
```

或提供想法:
```
爆款老年故事: 母亲节儿子给我8.8,给岳母8万8
```

### 执行流程
```
1. AI自动判断类型(A/B/C)
2. 生成核心设计 → 等用户确认
3. 生成精准字数蓝图 → 等用户确认
4. 写作1-4章 → 自动检查
5. 写作5-8章 → 自动检查
6. 去AI化润色 ⭐新增
7. 输出完整文档
```

## 📊 3种类型说明

### Type A: 悬念-往事-爆发-收尾 ⭐主力
**适合题材:**
- 带孙被弃
- 财产纠纷
- 母亲节偏心
- 长期付出被忽视

**特征:**
- 开头强悬念(数字冲突/被赶)
- 大量往事铺垫(50-60%)
- 冷静反击(卖房/断联/证据)
- 独立收尾

**字数分配:**
- 开场: 8%(900字)
- 往事: 55%(6300字) ← 核心
- 决策: 12%(1400字)
- 反击: 18%(2100字)
- 收尾: 7%(800字)

---

### Type B: 平静-揭秘-真相-和解
**适合题材:**
- 血型秘密
- 身世之谜
- 隐瞒多年的牺牲
- 误解的真相

**特征:**
- 开头平静(日常场景)
- 秘密层层揭开(3层递进)
- 真相大白(情绪高潮)
- 温情和解

**字数分配:**
- 开场: 18%(2000字)
- 揭秘: 45%(5200字) ← 核心
- 真相: 28%(3200字) ← 高潮
- 和解: 9%(1100字)

---

### Type C: 冲突-压抑-爆发-独立
**适合题材:**
- 离婚多年被邀请
- 长期疏离
- 冷战拒绝
- 直接矛盾

**特征:**
- 开头强冲突(非悬念)
- 几乎无往事回忆
- 当下压抑感极强
- 果断拒绝+划界

**字数分配:**
- 冲突: 10%(1150字)
- 压抑: 50%(5750字) ← 核心
- 爆发: 23%(2650字)
- 独立: 17%(1950字)

## ✅ 质量保证

### 字数精准
- 总字数: 11000-12000字
- 误差率: <1%
- 单章不超硬上限

### 去AI保证
- 20条检查清单
- 禁用AI词汇
- 对话真实(老年人语气)
- 细节具象(物品锚点)

### 节奏保证
- 3种类型各自节奏
- 量化到每1000字
- 必详写vs必简写明确

---

## 🔧 关键特性

### 台湾元素(保留)
- 阿嬷/阿姨/透天厝
- 健保卡/地政事务所
- 菜市场/便利商店
- **简体输出**

### 去AI化原则
- 无significance词(testament/pivotal)
- 无promotional词(nestled/vibrant)
- 无filler(in order to)
- 无chatbot痕迹(Here is)
- 身体反应代替情绪
- 具体细节代替抽象

### 克制的爆发
- 60%压抑 + 30%反击 + 10%升华
- 反击靠智慧非暴力
- 结局是"松口气"非"大获全胜"

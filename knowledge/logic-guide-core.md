# 老友逻辑核心原则（精简版）

> 本文件提取老友逻辑的核心方法论，详细案例解析请参考logic-guide-advanced.md（可选阅读）

## 一、核心公式系统

### 公式1：假性恶人（Fake Villain）
**结构：** 看似坏的人 → 实际是因为爱、愧疚、羞耻、无奈

**典型表现：**
- "嫌弃"的儿子 → 其实是债务压力/心理疾病
- 冷漠的丈夫 → 其实是隐瞒保护性秘密
- 严厉的婆婆 → 其实是害怕成为拖累
- 苛刻的雇主 → 其实是把对方当家人

**核心价值：** 让读者看到的不是"坏"，而是"人性"

---

### 公式2：误会推进器（Misleading Love）
**误会来源：**
1. 时间差（过去的事，现在才知道）
2. 角色期待不同（我以为你懂，你以为我明白）
3. 沉默者不解释（老人不爱说，年轻人不爱问）
4. 道具误读（照片、信件、红包、账单）

**误会作用：** 不是制造冲突，而是制造"情感纵深"

**设计要点：**
- 误会要有3-5个层次，层层递进
- 每个误会背后都有合理动机
- 误会解开要靠物证，不靠嘴说

---

### 公式3：物证反转法
**物证类型：**
- 泛黄纸张：病历、送货单、信件、账单、契约
- 老物件：手套、相片、木盒、首饰、衣物
- 空间细节：老宅两副碗筷、保留的房间、墙上的照片
- 电子记录：银行转账备注、手机备忘录、通话记录

**物证三大用法：**
1. **回忆型：** 触发回忆，解释过去（如老照片）
2. **未来型：** 揭示计划，理解动机（如遗嘱、存款）
3. **陷阱型：** 假物证误导，真物证反转（如假遗嘱测试）

**核心原则：** 老人不爱吵，他们用物证"证明一生"

---

### 公式4：生活流波形节奏（Soft Climax）
**节奏结构：**
```
平静生活细节（200字）
    ↓
小冲突-生活类（300字）
    ↓
中冲突-误会升级（400字）
    ↓
情绪崩点-沉默型（500字）← 不是吵架，是沉默
    ↓
反转-物证出现（600字）
    ↓
和解与成长（400字）
```

**关键要点：**
- 不要戏剧化爆发（老人不会大吵大闹）
- 情绪崩点用"沉默"、"眼泪"、"转身离开"
- 和解要克制，不要抱头痛哭

---

### 公式5：动机即"忍耐"
**老人行为动机的五大来源：**
1. 为了不拖累别人 → 不说
2. 为了面子与自尊 → 不说
3. 为了爱或愧疚 → 更不说
4. 为了给对方留好印象 → 硬撑
5. 为了保护家人 → 承担所有误会

**核心逻辑：**
> "宁愿让你误会我，也不愿你受伤。"
这句话可以解释90%的老年故事逻辑。

---

## 二、人物设定原则

### 主角设定（老年女性）
**基础信息：**
- 年龄：65-75岁最常见
- 背景：台湾或海外华人生活圈
- 性格：坚韧、隐忍、善良但不软弱

**内在撕裂（必须有）：**
- 渴望被爱 ⟷ 不想成为负担
- 想要公平 ⟷ 怕伤害家人
- 坚持传统 ⟷ 理解现代困境

### 配角设定（6-8人）
**必备角色：**
- 子女2-3人（各有立场和压力）
- 儿媳/女婿1-2人（独立人格，不是工具人）
- 老伴/前夫1人（可缺席但有影响）
- 邻居/朋友1人（见证者/陪伴者）

**配角原则：**
1. 每个人都有独立动机（不能只为推动剧情）
2. "反派"在他视角下必须合理（除非Type-3/6允许真反派）
3. 所有人都有脆弱性（没有完人）

## 三、关键检查清单

### ✓ 物证逻辑检查
- [ ] 主角为什么会在这个时间点接触物证？
- [ ] 物证放在哪里？为什么之前没碰到？
- [ ] 物证信息怎么一层层出来？
- [ ] 物证信息够不够？还需要佐证吗？
- [ ] 因果链条是否顺畅？

### ✓ 人物动机检查
- [ ] 每个配角都有独立动机吗？
- [ ] "反派"在他视角下合理吗？
- [ ] 儿媳/女婿有独立人格吗？
- [ ] 每个人物都有脆弱性吗？

### ✓ 误会设计检查
- [ ] 有3-5个层次的误会吗？
- [ ] 每个误会都有合理来源吗？
- [ ] 误会能靠物证解开吗（不靠嘴说）？
- [ ] 误会之间有递进关系吗？

### ✓ 情感深度检查
- [ ] 困境能被"给钱"简单解决吗？（能→深度不足）
- [ ] 有明确的价值观议题吗？
- [ ] 3类读者都有代入点吗？（65岁母亲/35岁子女/30岁儿媳）
- [ ] 结局留白了吗？（不要完美大团圆）

## 四、生活颗粒度密度表

### 台湾生活细节（必须密集出现）
**家庭场景：**
- 透天厝、公寓、老宅、眷村
- 神明厅、佛堂、祖先牌位
- 铁窗、晒衣竿、除湿机

**日常物品：**
- 健保卡、悠游卡、身分证
- 便当、小吃摊、夜市
- 电锅、瓦斯炉、铝制锅

**社交场景：**
- 菜市场、早餐店、公园散步
- 长青中心、社区活动、扫墓
- 邻里串门、楼下聊天

### 情绪表达细节（用动作不用形容词）
**不说"她很难过"，而写：**
- 她转身去厨房，切菜的手顿了顿
- 她盯着电视看，但眼睛没对焦
- 她把碗筷收得很慢，一个一个擦

**不说"他很愧疚"，而写：**
- 他低头看着脚尖，半天没抬起来
- 他想说话，喉结动了几次，没出声
- 他转身快步走了，像是逃一样

## 五、写作技术要求

### 语言风格
- **台湾口语化：** "阿嬷"、"阿伯"、"啦"、"捏"
- **短句为主：** 平均15-20字/句，长短交替有节奏
- **情绪藏在动作里：** 不直接说情绪，用动作和身体反应

### 禁用AI味词汇（严格执行）
**绝对不用：**
- 终于、深深、狠狠、默默
- 心中一紧、泪水模糊了双眼
- 她的心像被针扎了一样
- 往事如潮水般涌来

**替换方案：**
- 不说"她心中一紧" → 写"她手抖了一下"
-不说"泪水模糊了双眼" → 写"她把头转向窗外"
- 不说"往事涌来" → 直接写回忆场景

### 情感克制原则
- 不说教（不要"我明白了XXX道理"）
- 不煽情（不要"终于"、"深深"）
- 留白让读者思考（结局不要讲太满）

---

## 六、类型与反派设定对照

### 【需要"误会型反派"的类型】
- Type-1 付出错位型
- Type-4 婚姻冰封型
- Type-7 秘密揭晓型
- Type-9 代际和解型

**要求：** 反派在他视角下必须合理，结局是"理解与和解"

### 【允许"真反派"的类型】
- Type-3 黄昏情变型
- Type-6 财产争夺型

**允许：** 有真小人（嫌贫爱富、虚荣、冷暴力）
**要求：** 报应要巧妙（信息差、时机巧合），不是爽文式暴打

---

## 使用建议

1. **阶段0（深度挖掘）：** 重点用公式1、2、5理解人物动机
2. **阶段1（蓝图生成）：** 重点用公式3设计物证，用公式4安排节奏
3. **阶段2（逻辑验证）：** 使用检查清单逐项验证
4. **阶段3（文案写作）：** 重点参考生活颗粒度和写作技术要求

# 五大引爆公式

> 可直接套用的剧情结构模板
> 
> 用于【阶段2:逻辑验证】和【阶段3:文案生成】,确保情绪引爆点设计合理

---

## 📋 公式速查表

| 公式 | 适用类型 | 核心机制 | 引爆点数量 |
|-----|---------|---------|-----------|
| 错位认知公式 | 看错人型、付出错位型 | A好B坏→完全相反 | 3次 |
| 秘密暴露公式 | 婚姻冰封型、秘密揭晓型 | 秘密分层揭露 | 3次 |
| 付出崩塌公式 | 付出错位型、子女抛弃型 | 付出→被辜负→停止→真相 | 3次 |
| 晚年觉醒公式 | 老年觉醒型、黄昏情变型 | 忍耐→爆发→放手→新生 | 3次 |
| 误会和解公式 | 代际和解型、陌生人温情型 | 隔阂→爆发→真相→和解 | 3次 |

---

## 公式1:错位认知公式

### 适用场景
- 老人以为A是好人,B是坏人
- 结果完全相反

### 5幕结构

```
【第1幕:建立错误认知】(1500-2000字)
场景: A表现孝顺,B表现冷漠
情绪: 老人偏爱A,疏远B (情绪0,习以为常)
结尾钩子: A做出让老人很满意的事

【第2幕:强化错误认知】(2000-2500字)
场景: A继续表演,B依然冷淡
情绪: 老人更确信自己的判断 (情绪+3)
结尾钩子: 老人做出偏心决定(遗产给A)
★ 第1次引爆: A的虚伪露出破绽

【第3幕:认知开始动摇】(1500-2000字)
场景: 老人意外看到A的破绽/B的付出
情绪: 开始怀疑,但还不确定 (情绪-5)
结尾钩子: 老人决定暗中调查
★ 第2次引爆: 老人意外发现B的付出

【第4幕:真相大白】(2500-3000字)
场景: 物证揭晓,A是演戏,B是真心
情绪: 震惊,悔恨,羞愧 (情绪-10,触底)
结尾钩子: 老人向B道歉
★ 第3次引爆: 真相彻底揭开,老人情绪崩溃

【第5幕:弥补遗憾】(1500-2000字)
场景: 老人修改遗嘱/补偿B
情绪: 平静,接受自己的错误 (情绪+2)
结尾: B原谅老人,关系修复但留遗憾
```

### 情绪波形图
```
+5 |                    
   |      
 0 |■─────■             
   |       \          /■
-5 |        \    ■  /
   |         \  /  \/
-10|          ■/     
   └─────────────────────
   幕1  幕2  幕3  幕4  幕5
```

### 物证设计(三层递进)

**第1层:引发怀疑**
- A的假证据被戳穿
  - 伪造的转账记录
  - 假的照顾日志
  - 演戏被人看穿
  
**第2层:确认方向**
- B的真证据浮现
  - 默默的付出(邻居证词)
  - 隐藏的账单(偷偷给钱)
  - 医院记录(一直在照顾)
  
**第3层:彻底坐实**
- A的真面目
  - 欠债/出轨/算计
  - 当面对质崩溃
  - 第三方完整证词

### 关键台词设计

**A的假孝顺台词:**
- "妈,您放心,我会好好照顾您的"
- "妈,我最孝顺了,您有什么需要就跟我说"
- (背后):"反正老太太也活不了几年了"

**B的沉默付出:**
- (不说,用行动)
- "妈,您好好休息"(简短)
- (被误会时)"算了,随便您怎么想"

**老人的觉醒:**
- "我怎么会看错这么多年?"
- "对不起,是我对不起你"
- "我现在补救,还来得及吗?"

### 案例套用

**故事38:遗产分配错误**
- A=老大老三(表面孝顺)
- B=二儿子(沉默付出)
- 物证=生病记录/邻居证词
- 反转="遗产没我的份,养老也没我的责"

**故事39:养子30年**
- A=养子(长大应该感恩)
- B=继母(付出30年)
- 物证=借钱被拒/年薪300万却冷血
- 反转="一块钱也不给你"

### 避坑清单
- [ ] A不能是纯恶人,要有合理动机
- [ ] B不能太完美,要有缺点
- [ ] 老人的"看错"要有合理性
- [ ] 真相揭开不能一次性,要分层
- [ ] 结局要留遗憾,不是完美和解

## 公式2:秘密暴露公式

### 适用场景
- 某人隐藏秘密N年
- 秘密被揭开,改变所有关系

### 5幕结构

```
【第1幕:日常生活埋伏笔】(1500-2000字)
场景: 生活中反常行为
情绪: 平静但有不对劲 (情绪0)
伏笔: 上锁的抽屉/神秘电话/反常举动

【第2幕:老人起疑】(2000-2500字)
场景: 老人开始调查
情绪: 起疑,不安 (情绪-3)
结尾钩子: 发现第一层证据
★ 第1次引爆: 发现反常证据(上锁的抽屉/奇怪的存折)

【第3幕:秘密部分暴露】(1500-2000字)
场景: 秘密冰山一角
情绪: 震惊,但不是全部真相 (情绪-6)
结尾钩子: 误以为是坏事(出轨/背叛)
★ 第2次引爆: 秘密冰山一角(发现病历/听到对话)

【第4幕:完整真相揭开】(2500-3000字)
场景: 当事人坦白+物证坐实
情绪: 情感爆发 (情绪波动剧烈±10)
结尾钩子: 根据秘密性质决定走向
★ 第3次引爆: 完整真相(当事人坦白+物证坐实)

【第5幕:关系重构】(1500-2000字)
场景: 和解/决裂/承担新责任
情绪: 平静,但永远改变了 (情绪±3)
结尾: 留白,不说破
```

### 物证设计(三层递进)

**第1层:引发怀疑**
- 上锁的抽屉/书房
- 神秘的电话/短信
- 经常外出不说去哪
- 存折上有奇怪的转账

**第2层:确认方向**
- 医院诊断书
- 旧信件/日记
- 照片/录音
- 第三方证词

**第3层:完整真相**
- 当事人当面坦白
- DNA/亲子鉴定/医学证明
- 完整的时间线重构
- 所有疑点被解释清楚

### 案例套用

**故事11:分房35年**
- 秘密=丈夫心脏病不敢同床
- 第1层=上锁的书房
- 第2层=诊断书和信件
- 第3层=丈夫坦白
- 结局=和解,重新靠近

**故事29:嫌弃40年**
- 秘密=儿子不是丈夫亲生
- 第1层=丈夫一直冷漠
- 第2层=妻子拿出纸条
- 第3层=亲子鉴定报告
- 结局=解开心结,丈夫离世

### 避坑清单
- [ ] 秘密要有"隐瞒的合理性"
- [ ] 不要一次性说完,要分层揭露
- [ ] 第3幕的"部分真相"要合理
- [ ] 物证出现要自然,不是天降
- [ ] 结局要有"早说不就没事了"的遗憾感

## 公式3:付出崩塌公式

### 适用场景
- 老人长期单向付出
- 被辜负后停止付出
- 发现真相后和解或决裂

### 5幕结构 + 情绪波形

```
【第1幕:长期付出】(1500-2000字)
场景: 老人依然在付出
情绪: 满怀期待 (情绪+5)
结尾: 某个事件触发质疑

【第2幕:付出不被看见】(2000-2500字)
场景: 生病没人管/被嫌弃
情绪: 委屈 (情绪-3)
★ 第1次引爆: 付出到极限遭遇冷遇

【第3幕:停止付出】(1500-2000字)
场景: 老人停止付出,对方冷漠
情绪: 心寒 (情绪-8,触底)
★ 第2次引爆: 停止付出,对方露出真面目

【第4幕:真相揭开】(2500-3000字)
场景: 发现对方有苦衷/真自私
情绪: 复杂 (情绪波动)
★ 第3次引爆: 发现真相(正向:有苦衷 OR 负向:真自私)

【第5幕:新的平衡】(1500-2000字)
场景: 和解/断绝
情绪: 平静 (情绪+3 or 0)
结尾: 不回到从前,新的相处模式
```

### 情绪波形(经典型)
```
+5 |■                      和解
   |  \                   /
 0 |   \                /  断绝
   |    \──■          ■
-5 |        \        /
   |         \      /
-10|          \    /
   |           ■  ← 触底
   └─────────────────────
   幕1  幕2  幕3  幕4  幕5
```

### 案例套用

**故事2:每月2万的付出**
- 付出=每月给2万
- 触发=住院7天无人问
- 停止=取消转账
- 真相=儿媳产后抑郁
- 结局=和解,但方式改变

**故事26:被嫌脏赶走**
- 付出=远赴欧洲帮忙
- 触发=被嫌脏赶走
- 停止=回台湾
- 真相=儿子失业焦虑
- 结局=儿子道歉,关系修复

## 公式4:晚年觉醒公式

### 适用场景
- 老人忍了大半辈子
- 某个事件成为最后一根稻草
- 决定为自己活

### 5幕结构

```
【第1幕:习惯性隐忍】(1500-2000字)
情绪: 麻木 (情绪-2)
场景: 做不喜欢的事/维持表面和平

【第2幕:最后一根稻草】(2000-2500字)
情绪: 崩溃,反而冷静 (情绪-10→0)
★ 引爆: 被伤害到极限

【第3幕:惊人决定】(1500-2000字)
情绪: 坚定 (情绪+2)
★ 引爆: 提离婚/搬走/断联

【第4幕:周围人震惊】(2500-3000字)
情绪: 平静 (情绪0)
★ 引爆: 拒绝所有挽留

【第5幕:活出自我】(1500-2000字)
情绪: 平和的幸福 (情绪+5)
场景: 新的生活方式
```

### 案例套用

**故事28:忍了50年提离婚**
- 隐忍=50年凑合婚姻
- 稻草=儿子离婚+丈夫说"别学我"
- 决定=提出离婚
- 挽留=丈夫追到安养中心
- 新生=开早餐店自食其力

## 公式5:误会和解公式

### 适用场景
- 双方因误会隔阂多年
- 某个事件逼他们见面
- 真相揭开后和解

### 5幕结构

```
【第1幕:冷战现状】(1500-2000字)
情绪: 双方冷漠 (情绪-5)

【第2幕:被迫见面】(2000-2500字)
情绪: 尴尬 (情绪-3)
★ 第1次引爆: 被迫见面

【第3幕:矛盾爆发】(1500-2000字)
情绪: 说出积压多年的话 (情绪-10)
★ 第2次引爆: 正面对峙

【第4幕:真相揭开】(2500-3000字)
情绪: 痛哭,释放 (情绪+8)
★ 第3次引爆: 原来双方都是为对方好

【第5幕:和解】(1500-2000字)
情绪: 平静,珍惜 (情绪+5)
结尾: 重建关系,不完美但真实
```

### 案例套用

**故事26:儿子赶走母亲**
- 隔阂=儿子赶走母亲
- 被迫=母亲收到200万
- 爆发=母亲质问儿子
- 真相=儿子失业焦虑
- 和解=母亲回欧洲陪伴

## 💡 使用指南

### 如何选择公式?

**根据故事走向:**
1. 认知反转 → 公式1
2. 秘密揭开 → 公式2
3. 付出被辜负 → 公式3
4. 老人觉醒 → 公式4
5. 代际和解 → 公式5

### 可以混合吗?

**可以!** 一个故事的不同阶段用不同公式:
- 前半段用公式3(付出崩塌)
- 后半段用公式5(误会和解)

### 质量自检

- [ ] 三次引爆点是否清晰?
- [ ] 情绪波形是否合理?
- [ ] 物证三层是否自然?
- [ ] 结局是否留白?

---

**核心原则:**
- 公式是工具,不是枷锁
- 真实感>完美套用公式
- 情绪要克制,不要用力过猛
- 引爆点要自然,不要刻意制造

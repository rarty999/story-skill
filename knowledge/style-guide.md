# 写作风格指南

---

> **首要原则：这里的规则是辅助指南，不是死条款。如果成品文案（examples/）里的写法跟这里某条规则冲突，跟成品文案走。**
>
> 风格不是套公式能套出来的。真正的目标是：**听起来像一个台湾阿嬷在真的讲话。**

---

## 一、核心语气：克制、温吞、轻说

写这种故事的核心感觉，就是一个人坐在那里，把事情慢慢讲给你听。不急。不激动。偶尔停一下，想想，再继续。

语气三个方向：
- 不指责、不哭喊、不咆哮
- 回望式——不是在事件当下吵，是多年后轻轻回顾
- 苦而不悲、怨而不恨、酸中带暖、冷后回甜

## 二、句式节奏：有起伏，不要匀速

台湾阿嬷讲话，不是每句都一样长。有时候三个字，有时候十几个字。会重复同一个词，不会刻意换同义词。会卡壳，说一半停住。偶尔会说一句废话（"就是那种…"、"反正…"）。

这些"不完美"不是错误，是最重要的人味来源。

**短句是基础**，但不要每句都切得一样短。那反而会变成一种机械的节奏感，跟真人说话不像。长短交替才是自然的。

参考感受：
```
✅ 自然节奏（来自成品文案）：
"那天晚上,饭桌上四菜一汤。
我刚把鱼城给女婿,她忽然放下筷子,轻轻敲了三下桌子,语气不重,却向一道冷风。
那一刻,我的手停住,筷子在半空。
我笑著说,没事,心里却慢慢凉下去。"

——看到了吗？第一句短。第二句很长，但是一整个动作的描述。第三句又短。第四句是回到自己的感受。
这种长短交替，才是真人口述的节奏。

❌ 机械短句（每句都切）：
"我提着行李箱。
楼梯很冷。
慢慢走。
儿子刚才的话，一直在脑子里转。
越想，越委屈。"

——这个虽然也可以，但如果全篇都是这种一样的节奏，读起来会很单调。
```

## 三、台湾口语化表达

语言要贴近台湾生活圈，但不需要刻意塞入方言词。自然的台湾口语就够了。

常见参考：
- 称谓：阿嬷、阿公、阿姨、叔叔
- 语气词：啦、噢、哦、嘛（用得自然就好，不要堆）
- 场景词：透天厝、老公寓、铁门、阳台、菜市场、便利商店、健保卡、捷运、机车、除湿机、垃圾车音乐

## 四、生活颗粒度：让人身临其境

这是这种故事最重要的质感来源之一。不是在描述，是让读者感觉自己就在那个场景里。

**核心原则：不要用氛围词。用具体的看到、听到、闻到。**

```
❌ 氛围词：
"温馨的家庭氛围"
"宁静的小镇生活"

✅ 具体感知（来自成品文案）：
"厨房的灯亮著,水声犀利,楼上传来轻轻的脚步声,电视光闪在地板上"
"外头传来垃圾车的音乐。"
"阳光照到地板的一块,正正方方。"
```

生活颗粒度不是要凑数量，是让每个场景都是真实的、可感知的。场景里有声音、气味、光线、温度。台湾那些日常的东西——垃圾车、除湿机嗡嗡响、菜市场的味道、便利商店的灯光——这些出现在对话里就好，不用刻意强调。

### 生活颗粒度的高级用法:感官对立 ⭐新增

不只是"具体的看到、听到、闻到",更要用**"对立感官"**制造张力和隐喻。

**气味对立:**
```
✅ 爆款案例:
"家里的油烟味/肥皂味"(代表付出与糟糠之妻)
VS
"外面的廉价香水味"(代表虚荣与背叛)

金句:"那股香水味。干净,又刺,不是我家的味道。"
→ 比直说"他出轨了"高级太多
```

**声音对立:**
```
✅ 对我的语气 VS 对她的语气
"你还是回去比较好。"(冷淡、不耐烦)
VS
哼着歌、大笑(对女舞伴温柔)
```

**物品对立:**
```
✅ 我的旧布包(低调、底气)
VS
她的新皮包(虚荣、空洞)

我的粗茶淡饭
VS
外面的精致餐厅
```

**使用时机:**
- Type-3 黄昏情变型(最适合)
- Type-6 财产争夺型
- 需要制造"背叛感"的场景

**注意:**
- 不要堆砌,一个场景1-2处对立即可
- 要自然融入,不刻意强调
- 让读者自己感受,不明说

## 五、情绪表达：藏在动作和身体反应里

这是银发故事的核心技巧。主角不会说"我很伤心"，也不会大哭大喊。情绪是通过身体反应和细小动作流出来的。

```
❌ 直接说情绪：
"我非常伤心。"
"我很生气。"

✅ 身体反应（来自成品文案）：
"那一刻,我的手停住,筷子在半空。"
"喉咙紧紧的,像是被什么卡住了。"
"脚软了一下,站不太稳。"
"手机握着,手指慢慢收紧。"
"胸口闷,很闷。"
```

但注意：身体反应也不要堆太多。一个场景里放一两个就够了。放多了反而假。

常用身体反应参考（根据情绪类型）：
- 震惊：整个人愣住、脚底发麻、脑袋嗡一声
- 悲伤/委屈：心里刺一下、喉咙紧紧的、眼眶热了、鼻子酸
- 恐惧/不安：背后发凉、手心出汗、腿软
- 愤怒/压抑：胸口闷、手指发抖、整个人绷紧

## 六、对话：短、真、生活化

对话要像真人说话。不长，不刻意。一句话就能推动情节或者流露关系。

```
✅ 来自成品文案的对话感受：
"妈,你还是回去比较好。"
"好,没关系,我习惯了。"

"妈,你头发又白了。"
"早就白了。"

"妈,你别太累哦。"
"我这把年纪,怕闲不怕累。"
```

对话推动情节的几种用法：
- 一句话流露关键信息（不要解释，说出来就够了）
- 童言戳心（小孩说出大人不敢说的话）
- 半说半藏（说一半停住，制造悬念）

### 对话的"寸劲"技法 ⭐新增

> 用最少的字,制造最大的冲击

**什么是"寸劲"?**
像武术里的寸拳,短距离爆发出巨大力量。对话也一样,不需要长篇大论,几个字就能致命一击。

**四种寸劲对话:**

**1. 极简反讽**
```
✅ 爆款案例:
丈夫以为占了便宜净身出户
女主:"好,财产都给你。"
→ 她知道有陷阱,表面顺从实则讽刺

离婚后丈夫求复合
女主:"迟了。"
→ 两个字,一生的遗憾
```

**2. 一语双关**
```
✅ "我不是赌钱,是在赌人。"
→ 表面说麻将,实际说人性
```

**3. 冷静戳穿**
```
✅ "你现在讲话这么软,
    是为了我吗?还是为了钱?"
→ 直击动机,不给面子
```

**4. 轻蔑定性**
```
✅ "你就是家里的人。"
→ 极度轻蔑,把妻子物化
```

**使用原则:**
- 重要转折点才用
- 一场戏最多1-2句
- 前面要有铺垫,才有爆发力
- 说完不解释,让它悬在空气里

**适用场景:**
- 摊牌对峙
- 拒绝复合
- 揭穿谎言
- 最后告别

# 口述感强化指南

---

## 六之一、口述感的核心：对话与叙述的平衡

> **不是要对话多，是要让整篇文字"听起来像在讲话"。**

### 什么是"口述感"？

成品文案读起来，就像一个阿姨坐在你对面，泡着茶，慢慢跟你讲。这种感觉来自：

1. **对话和叙述的自然穿插**（不是全对话，也不是全叙述）
2. **说话的"不完美"**（重复、卡壳、插话）
3. **心里话的自然流露**（边讲边想起什么就说什么）

### 对话的使用时机

**什么时候用对话？**

✅ 需要对话的场景：
- 人与人的互动（舞蹈班、家庭聚会、朋友聊天）
- 冲突爆发的时刻（吵架、摊牌、说出真相）
- 关键信息的传递（宣布某件事、揭露秘密）
- 制造现场感（让读者感觉身临其境）

❌ 不需要对话的场景：
- 回忆往事（用叙述更有回望感）
- 内心挣扎（用心里话和身体反应）
- 环境描写（用感官细节）
- 时间跳跃（用简短叙述过渡）

### 对话的密度参考

**不是固定比例，是看场景需要：**

- 社交场景（舞蹈班、聚会）：对话可以占60-70%
- 家庭冲突场景（争吵、摊牌）：对话占50-60%
- 独自思考场景（回家路上、躺在床上）：对话占0-10%
- 回忆场景（讲过去的事）：对话占20-30%

**平均下来，一篇1万字文案，对话约占30-40%是自然的。**

---

## 六之二、对话写作的实战技巧

### 1. 对话要推进情节

对话不是为了"聊天"，是为了推动故事：

✅ 成品文案的例子：
```
老师拿着麦克风，声音已经沙哑，各位，今天是我们这一期的结业，大家辛苦了。
他停了一下，露出那种要宣布什么惊喜的表情。
不过，人不会因为结业，就人生结束吗？对不对。
所以我在想一个点子。

蔡美芝马上接话，老师又要揪团了吼！
```

→ 这段对话做了什么？
1. 宣布结业（交代背景）
2. 引出温泉团（推进情节）
3. 展现人物性格（蔡美芝爱热闹）
4. 制造现场感（大家的互动）

### 2. 对话要配场景和动作

对话不能凭空出现，前后要有动作、表情、停顿：

❌ 错误（光秃秃的对话）：
```
"你要去吗？"
"我想去。"
"那你老公同意吗？"
"不知道。"
```

✅ 正确（对话配场景）：
```
方运如拍拍我的手，素真，你有兴趣吗？
我笑笑，还没说话。
她又说，叫你老公一起去啦，有男人在比较方便。
我看着她，嘴巴张了张，想说什么，最后只说，我回去问问看。
声音小得自己都快听不见。
```

### 3. 对话要"抢"和"接"

真人聊天不是你一句我一句轮流说，是会抢话、接话茬的：

✅ 成品文案：
```
老师：我在想，要不要办一个温泉养生团...
（还没说完）
蔡美芝：老师又要揪团了吼！
（一群阿姨立刻笑成一片）
```

这就是真实的对话现场，不是礼貌地等别人说完。

### 4. 对话要短

老年人说话，一句话通常10-20字：

❌ 太长：
```
"我觉得这个提议很好，我们应该认真考虑一下，毕竟这是一个难得的机会。"
```

✅ 正确：
```
"我觉得可以。"
停了一下。
"难得的机会。"
```

## 六之三、叙述写作的实战技巧

### 1. 叙述要"像在说话"

叙述不是客观陈述，是主角在跟你讲她当时的感受：

❌ 客观叙述（像报告）：
```
那天晚上我回到家，老公在看电视。我想跟他说温泉团的事，但是没有说出口。
```

✅ 口述叙述（像讲话）：
```
回到家，老公窝在沙发上，电视开着。
温泉团的事，话到嘴边，又吞回去。
我看了，他应该是舍不得离开沙发跟电视。
```

→ 看到差别了吗？第二个有"心里话"（"我看了，他应该是..."）

### 2. 叙述要有"心里话"

成品文案的秘密：主角一边讲事情，一边说她怎么想的：

✅ 成品文案：
```
"我嘴巴讲得轻松，心里确实另外一个味道。"

"我说完，旁边的人都笑了。
只有我自己知道，那笑声里有多少勉强。"
```

这就是口述感。她在跟你说她当时的真实想法。

### 3. 叙述要"碎"一点

不要写长段落，要切碎，像说话时的停顿：

❌ 一大段叙述：
```
那天晚上我回到家想起白天的事情老师说要办温泉团大家都很兴奋我也想去但是想到老公可能不同意心里就不安不知道该怎么说。
```

✅ 切碎的叙述：
```
那晚回家的路上，车窗外的路灯，一盏接一盏闪过去。
我看着自己的倒影。
温泉团。
老师说的那句话，一直在脑袋里转。
我想去。
可是老公那张脸，又浮上来了。
```

### 4. 叙述要有"重复"

真人讲话会重复，不要刻意换同义词：

❌ AI写法（刻意换词）：
```
我看着他。我注视着他的背影。我目送他离开。
```

✅ 真人讲法（自然重复）：
```
我看着他走。
看着他的背影。
一直看，看到他消失。
```

## 六之四、口述感的"小技巧"

这些技巧不用全部用，但偶尔用一两个，可以让文字更有人味：

### 技巧1：卡壳

说到一半停住，太痛了说不下去：

```
"我那时候傻，觉得有女生喜欢他，是我有眼光。
直到有一天，我在他外面租的小套房...
（停顿）
我整个人都傻掉。"
```

### 技巧2：自问自答

```
"等到现在，我头发白了一半，人也退休了。
那些以后都被丢到不知道哪里去。
温泉养生团。
听起来，好像有一点不切实际。
又好像，把我年轻时那个小小的梦，又捡回来了。"
```

### 技巧3：插入回忆

讲着讲着突然想起往事：

```
"我老公陈建明，今年六十六岁，做了一辈子贸易公司业务经理。
英文是不错啦，最会讲的就是Trust Me跟No Problem。
但他最相信的人，从来不是我。"

→ 讲职业的时候，突然插一句心里话
```

### 技巧4：废话

偶尔说一句看似没用的话：

```
"就是那种..."
"反正..."
"我看了..."
"说实在的..."
"想起来..."
```

这些词不要删得太干净，偶尔留一两个，会更自然。

## 六之五、实战对比示例

### 场景：主角回家，想跟老公说温泉团的事但不敢说

**❌ 散文化写法（太文学，没有口述感）：**

```
那天晚上我回到家，老公正坐在沙发上看电视。我走进客厅，想要开口告诉他舞蹈班要办温泉团的事，但看到他疲惫的表情，我犹豫了。我心里很矛盾，一方面渴望能够参加这次旅行，一方面又担心他会反对。最后我还是决定暂时不说，等待一个更合适的时机。我默默地走进厨房，开始准备晚餐，心中却始终放不下那件事。
```

→ 这就是我之前写的问题：太完整、太顺、像散文

**✅ 口述化写法（对话+叙述+心里话）：**

```
回到家，老公窝在沙发上，电视开着，遥控器放大腿上。

"吃饱了？"他头都没转。

"吃了。"我把包包放下，走到厨房倒水。

"跳完舞很累吼？"

"还好。"

我端着水杯，站在客厅跟厨房中间那条线上。
温泉团的事，话到嘴边。
看他那个样子，我又把话吞回去。

他换了台，画面是新闻。

我喝了一口水。
喉咙还是紧紧的。

"我去洗澡了。"

"嗯。"

那天晚上，我躺在床上，一直睡不着。
窗外有机车声，一阵一阵传来。
我盯着天花板上那个水渍，想了很多。
```

→ 看到差别了吗？
- 有对话（但不多，因为他们本来话就不多）
- 有动作（倒水、换台）
- 有心里话（"话到嘴边，又吞回去"）
- 有身体反应（"喉咙紧紧的"）
- 句子长短不一（有停顿感）

## 六之六、最后的自检清单

写完之后，问自己：

1. **念起来顺不顺？** → 大声念一遍，卡的地方就是要改的地方
2. **有没有心里话？** → 不要只写发生了什么，要写她怎么想
3. **对话和叙述是否自然穿插？** → 不要一大段对话或一大段叙述
4. **有没有"不完美"？** → 重复、卡壳、废话，偶尔要有
5. **听起来像"讲话"还是"写文章"？** → 一定要像讲话

---

**记住：不是对话多就好，是整体要"听起来像一个人在讲话"。**

**对话是工具，叙述也是工具，心里话也是工具。根据场景需要来用。**

**最重要的测试：大声念出来。如果听起来像阿姨在聊天，就对了。**




## 七、叙事节奏：炸-铺-堆-炸-慢

YouTube老年故事的节奏跟一般散文不同。听众是在睡前或者做家务的时候听的，前10秒钩不住就会关掉。所以开头不能慢，必须先炸悬念，再回头铺陈生活。

整体节奏是这样的：

- **开头：炸（快）**。先把最吸引人的悬念丢出来，让人想听下去。然后才回头解释人是谁、日子怎么过的。
- **中段：铺+堆**。铺生活背景，堆误会。误会一层一层叠，情绪慢慢绷紧。
- **高潮：炸（快）**。物证出现，真相一层一层打开。节奏变快，但物证本身要写慢——让人跟着主角一起慢慢看。
- **结尾：慢**。和解，收束，余味。不急着收。

### YouTube快钩开头的具体结构（五步式）

林美芳故事修改后用的开头就是这种结构。这五步是固定的，顺序不要动：
第一步：超短自我介绍（1-2句）
→ 谁、多少岁、什么身份。就这么多。
例："我叫林美芳，今年68岁。结婚38年。"
第二步：悬念炸弹（2-3句）
→ 直接说"有一件事我藏了很久"或者"有一件事我发现了"。
→ 不要解释是什么事，就让人知道有这件事。
例："可去年，他退休以后，我发现，有一个东西，他藏了我几十年。"
第三步：情绪冲击（1-2句）
→ 用身体反应来说明这件事对她的重量。不要直说"我很shocked"。
例："那东西，我看到的那一刻，整个人像是被人从胸口挖出一块肉。"
第四步：互动钩子（固定句式）
→ 这句话是固定的，每篇都要放。
"如果你想听，我就继续讲下去，轻轻帮我点个赞，让我知道你还在听。"
第五步：闪回到物证发现的那个瞬间（3-5句）
→ 先给一个具体的画面——她在做什么、看到了什么。制造画面感。
→ 然后说"那个东西里面写了什么，我后面慢慢跟你说。"
→ 然后才切回来，"我先从...开始说起。"进入正常的生活铺陈。
例："那天晚上，我坐在耀生的衣柜前……里面是一本笔记……那本笔记里面写了什么，我后面慢慢跟你说。我先从退休那天开始说起。"

这五步完成之后，读者已经知道：（1）主角是谁；（2）有件大事；（3）这件事很重要；（4）主角愿意继续讲。然后才进入生活背景铺陈的部分，不会觉得无聊，因为悬念已经在那里了。

但这是大体趋势，不是严格的字数分配。根据故事本身的需要来灵活处理。
## 八、时间跨度：用具体数字

时间跨度是这种故事的情感重量来源之一。要用具体的数字，不要说"很久"。

```
✅ "分房35年" / "失联27年" / "照顾公公20年"
❌ "很多年" / "很久" / "长时间"
```

## 九、物证描写：必须有重量

物证是反转的核心。要具体，要有质感，要有时间痕迹。

三个要素：
1. **历史性** - 必须有足够的时间跨度
2. **情绪爆发力** - 能改写所有误会
3. **具体可感** - 不能抽象，必须是实物

发现物证的时候，描写要慢。让读者跟着主角一起慢慢感受。

## 十、结尾收束：温柔、克制、有余味

结尾不要给出答案。不要总结，不要说大道理。让读者自己去感受。

三个不要：
1. ❌ 不煽情
2. ❌ 不说教
3. ❌ 不爽文逆袭

好的结尾感受（来自成品文案）：
```
"没有多说什么。但饭桌上,多了一杯茶。"

"那一刻风进来,花香混著海味,我心里只想能这样抱著她,就够了。"

"风停下来的时候,我还坐在门口,听海浪拍著岸。"
```

就是这种——事情结束了，但还留着点什么。不急着收。

## 十一、常见错误清单

写的时候最容易掉进去的几个坑：

1. **过度文学化**："岁月如梭、光阴荏苒、心如刀绞" → 全删
2. **情绪外放**："我大声哭喊！我愤怒地摔门！" → 不会的，换成身体反应
3. **悬浮表达**："精致的生活""优雅的姿态" → 没有，全部换成具体场景
4. **戏剧化情节**："突然车祸""查出绝症""中彩票" → 不要，冲突要合乎情理
5. **台词太长**：超过20字的对话基本都要拆

## 十二、去AI味指南（核心检查机制）

> **这部分是严格的。不要松动。**

AI生成中文文字时，容易滑进特定的模式和用词。老年故事是第一人称口述体，本身就应该是"人味"格式，但如果不主动检查，AI很容易让整篇文案变成"总结报告"的语气。

### 前言：去AI味分两步

**第一步是去除坏的东西**——下面A到J项讲的就是这些。
**第二步是加入好的东西**——这才是让文字听起来像真人的关键。

很多文字，禁用词全部删掉了，句式也规范了，但读起来还是干干巴巴的，没有温度。原因是：它太整齐了。太完美了。真人不会说话那么整齐。

台湾阿嬷讲话的特征是：
- 会重复同一个词（不会刻意换同义词）
- 会卡壳，说一半停住
- 会突然绕回来补一句之前的话
- 句子长短不匀，有时候三个字，有时候十几个字
- 偶尔会说一句废话（"就是那种…"、"反正…"）

这些"不完美"不是错误，是最重要的人味来源。写的时候要刻意保留这种感觉，不要让文字太干净太顺滑。

---

### A. 中文AI高频词禁用库

以下词汇在AI生成文字中出现频率极高，老年故事正文里一个都不应该出现。遇到就替换。

```
禁用词                    → 替换方向
─────────────────────────────────────
深刻                      → 删除，用具体事件替代
此外                      → 删除，直接接下一句
彰显                      → 删除
体现了                    → 删除
凝聚                      → 删除
揭示了                    → 删除，用"我才知道"替代
感悟                      → 删除，用具体反应替代
转折点                    → 删除，直接写事件
意义深远                  → 删除
人生课题                  → 删除
心灵的                    → 删除
温暖的（泛指）             → 换成具体场景
浓郁的                    → 删除
珍惜                      → 用行动表达，不要直说
感激                      → 用行动表达，不要直说
从而                      → 删除
由此                      → 删除
不仅仅是……而是……          → 拆成两句普通句子
不仅……还……               → 拆开写
```

---

### B. 意义膨胀句式（AI最爱写的）

AI写中文故事时，特别爱在事件后面加一句"总结评价"。老年故事绝对不要。事件本身就够了，不需要你替读者总结。

```
❌ AI习惯写法：
"那一刻，我终于明白了人生的真正意义。"
"这件事让我深刻地体会到了亲情的珍贵。"
"从那以后，我对生活有了全新的感悟。"

✅ 正确写法：
"那一刻，我愣住了。"
（不加评价，让读者自己感受）

"我盯着那张纸，看了很久很久。"
（动作描写，不总结）
```

**核心原则：不要替读者想。只写发生了什么，怎么做的，身体怎么反应。**

---

### C. 广告化语言（场景描写里最易出现）

AI描写生活场景时，容易滑进"旅游攻略"的语气。

```
❌ 广告化写法：
"温馨的家庭氛围"
"浓郁的乡土风情"
"宁静的小镇生活"

✅ 正确写法（写具体）：
"厨房里还飘着煮饭的香味。"
"早上垃圾车经过，放着《少女的祈祷》。"
"饭桌上摆了三菜一汤，老公还在嘟囔太淡。"
```

---

### D. 同义词循环（一个场景里反复换词描述同一件事）

AI有强烈的"不要重复"倾向。老年故事里，重复是自然的。真人讲话就是会重复。

```
❌ 同义词循环：
"我看着他离开。
我目送他的背影消失。
我注视着他慢慢远去。"

✅ 正确写法：
"我看着他离开。
门关上了。
屋子里一下子安静得不像话。"
（切场景，不反复描述同一动作）
```

---

### E. 负向平行句式（AI特别爱用）

```
❌ AI习惯句式：
"这不仅仅是一个家庭的事，而是整个社会的缩影。"
"这不仅是一场和解，更是一场救赎。"

✅ 正确写法：
直接写事件本身就好。不要加"不仅……而是……"这种框架句。
```

---

### F. 凑三件事的习惯（AI爱凑三）

```
❌ 凑三件事：
"那天，她感受到了痛苦、困惑和希望。"
"回想起来，那些年最重要的就是爱、包容和理解。"

✅ 正确写法：
只写当时真的发生了什么。不凑。不总结。不分类。
```

---

### G. 破折号和连续副词滥用

```
❌ 破折号过量：
"她终于明白了——那些年他一直都在——只是用自己的方式——默默地守护。"

✅ 正确写法：
"她终于明白了。
那些年他一直都在。
只是他的方式，她当时没看见。"

❌ 副词堆叠：
"她慢慢地、轻轻地、小心翼翼地打开那封信。"

✅ 正确写法：
"她打开那封信。
动作很轻。"
```

---

### H. 填充词清除

这些词在AI文字里出现很多，但在真人口述里不自然。

```
删除这些词：
"其实"（大多数时候可以直接删掉）
"说实话"（删掉）
"可以说"（删掉）
"不得不"（很多时候用不上）
"终于"（用太多就失效了，最多全文用2-3次）
"突然"（同上，用多了就钝了）
"渐渐地"（删掉，直接写结果）
"不知不觉"（删掉，直接写变化）
"正是因为"（删掉，直接写原因）
"无非是"（删掉）
"说到底"（删掉）
"归根结底"（删掉）
"仔细想想"（删掉，直接接想到的东西）
"回想起来"（大多数时候可以删掉）
"说起来"（删掉）
"其中"（很多时候可以删掉）
"据说"（如果不是故事本身需要这个模糊感，删掉）
```

---

### H2. 句尾假深度（尾接总结句）

AI特别爱在一个事件的描述后面，尾接一句"意义总结"。

```
❌ 句尾假深度：
"他把钥匙递给我，动作很慢，让我感受到了他心中的不舍。"
（"让我感受到了他心中的不舍"是多的）

✅ 正确写法：
"他把钥匙递给我。
动作很慢。"
（就这样，不用再说为什么慢）
```

**规则：句子末尾如果出现"让我……"、"让人……"、"提醒我……"，十有八九是多的。删掉。**

---

### H3. 华丽动词替换"是"

```
❌ 华丽替换：
"那个房间变成了我思念的地方。"
"她成为了我心里最重要的人。"

✅ 正确写法：
"那个房间，就是我思念的地方。"
"她就是我心里最重要的人。"
```

**规则：能用"是"就用"是"。不要用"变成"、"成为"、"演变为"。**

---

### H4. 假范围句式（"从……到……"）

```
❌ 假范围：
"从年轻到老年，她一直在付出。"
"从一个普通的母亲到家里的支柱，她经历了太多。"

✅ 正确写法：
直接写具体发生了什么。不用"从……到……"来包装。
```

---

### I. 结尾不要"大道理"收束

```
❌ AI式大道理结尾：
"从这件事中，我学会了珍惜身边的人。"
"亲情永远是最重要的。"

✅ 正确结尾（有余味，无大道理）：
"后来，我们就这样过着日子。
没有多说什么。
但饭桌上多了一份碗筷。"
```

**核心原则：结尾不要给出答案。让读者自己去感受。**

---

### J. 去AI味自检流程

写完文案后，做这几步检查：

**第一步：搜索禁用词**
把文案丢进搜索，逐条检查A项禁用词库。有就替换掉。

**第二步：找意义膨胀句**
快速扫一遍，找"从而"、"由此"、"终于明白了"之类的总结句。删掉或换成动作描写。

**第三步：读结尾**
最后两段，有没有"大道理"？有就删掉，换成一个具体的小场景。

**第四步：念一遍**
把整篇文案默念一遍。哪里听起来像"报告"而不像"讲话"，就改哪里。

**第五步：找僵硬处**
找找哪里句子太整齐、太顺滑。真人讲话不会那么顺。需要的话，插一句卡壳、一次重复、一句废话。让它听起来像一个人在真的说话。

#### 十三 对话写作的核心原则

#### 1. 不要机械使用"他说/我说"

❌ 错误示范:
他说,你怎么了。
我说,没事。
他说,真的没事吗。
我说,真的。

✅ 正确示范:
"你怎么了?"他看着我。
"没事。"我转过头。
"真的没事吗?"他的手放在我肩上。
我沉默了一会儿,"真的。"

#### 2. 对话前后要加动作/表情/身体反应

对话不是凭空出现的,前后要有:
- 动作("他推了推茶几上的文件夹")
- 表情("他的脸色变了一下")
- 身体反应("我手一抖,水壶掉在地上")
- 停顿("他张了张嘴,想说什么,最终却只是...")

#### 3. 老年人对话的特点

a) 不说"我爱你",而是:
- "你这个傻瓜"(责备中带心疼)
- "不准再自作主张"(实际要求表达关心)
- "我们还有好多账没算呢"(打趣掩饰情感)

b) 多用反问句:
- "拖累什么?"(否定对方的理由)
- "你怎么这么傻?"(责备但关心)
- "不然呢?"(理所当然的语气)

c) 对话简短、直接:
- 紧张时更简短
- 不说长句解释
- 不文学化

#### 4. 对话的长短交替

不要每句对话都一样长:
- 有的一个字("嗯。")
- 有的一句话("我知道。")
- 有的带着动作和情绪("好。"我强忍着眼泪,拿起笔。)

#### 5. 对话要有"停顿感"

真人说话不是连续不断的:
- "他愣了一下"
- "沉默了一会儿"
- "半天说不出话来"

这些停顿比对话本身更重要。

## 十四、质量自检清单（完整版）

写完文案后，检查以下要点：

### 写作风格检查
✅ 场景里是否有具体的看到、听到、闻到？（不是氛围词）
✅ 情绪是否通过身体反应和动作流出来的？
✅ 对话是否简短、生活化？
✅ 时间跨度是否用了具体数字？
✅ 句子长短是否有自然的起伏？
✅ 语气是否克制、温吞？
✅ 结尾是否温柔收束、没有大道理？

### 去AI味检查
✅ 是否包含禁用词库里的词？（逐条搜索）
✅ 是否有"意义膨胀句"？
✅ 是否有广告化场景描写？
✅ 是否有同义词循环？
✅ 是否有负向平行句式？
✅ 是否凑了三件事？
✅ 破折号是否过量？
✅ 填充词是否已经清除？
✅ 结尾是否避免了大道理？
✅ 是否有句尾假深度？
✅ 是否用了华丽动词替换"是"？
✅ 是否有假范围句式？

### 注入灵魂检查
✅ 句子长短是否有变化？（不要每句都一样长）
✅ 是否有自然的重复？（真人会重复，不要全换同义词）
✅ 是否有卡壳或话说一半停住的感觉？
✅ 是否偶尔有一句废话？（"就是那种…"、"反正…"之类）
✅ 整体读起来是"一个人在讲话"还是"一篇文章在汇报"？

---

**核心理念：用最朴素的语言，讲最有重量的故事。听起来像一个真人在说话，不像一篇文章在汇报。**

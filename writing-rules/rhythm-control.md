# 节奏控制量化配方

**作用:** 每1000字应包含的情绪密度,解决"该详写的一带而过,该简写的啰嗦不停"

---

## 🎯 通用原则

### 情绪密度公式
```
每1000字 = 
  1个具体场景(带五感) +
  1个内心独白(心理变化) +
  1个小冲突/委屈 +
  0.5个物品锚点
```

### 必详写vs必简写

**必须详写(每处300-500字):**
- 触发事件场景
- 关键对话(含动作/表情/停顿)
- 物品细节(记账本/照片/合约)
- 往事回忆(Type A/B)
- 真相揭开场景
- 反击/摊牌场景

**必须简写(每处50-150字):**
- 时间过渡("隔天""一周后")
- 背景交代(年龄/职业/家庭)
- 地点移动("我走出银行""回到家")
- 次要人物介绍

## 📊 Type A: 悬念-往事-爆发-收尾 节奏配方

### 第1阶段: 开场悬念(900字)

**每300字配方:**
```
前300字: 身份+核心冲突数字化
├─ 必详: 开头3句(50字)
├─ 必简: 背景(<100字)
├─ 必详: 核心冲突具象(150字)

中300字: 触发事件场景
├─ 必详: 视觉/听觉冲击(200字)
├─ 必简: 过渡(<100字)

后300字: 第一反应+悬念
├─ 必详: 身体反应+内心独白(200字)
├─ 必详: 悬念钩子+互动引导(100字)
```

**检查点:**
- [ ] 开头50字内完成身份+冲突
- [ ] 无背景啰嗦(家庭成员/过往经历)
- [ ] 有具体数字/画面(8.8 vs 8万8/空房间)
- [ ] 结尾有悬念钩子

---

### 第2-4阶段: 往事铺垫(6300字)⭐核心

**每1000字配方:**
```
委屈场景(400字,必详):
├─ 具体事件(200字)
│   ├─ 场景: 菜市场/电话/看截图
│   ├─ 对话: 3-5句真实对话
│   └─ 细节: 物品/声音/温度
└─ 身体反应+内心独白(200字)

往事回忆(300字,必详):
├─ 时间标记("那年""XX年前")
├─ 场景具象(买房/带孙辛苦)
└─ 情感对比(温情→心寒)

过渡衔接(100字,必简):
├─ "我站起来"
├─ "回到家"
└─ "那天晚上"

物品锚点(200字,必详):
├─ 记账本/老照片/合约
├─ 具体描写(纸张/字迹/味道)
└─ 情感寄托
```

**往事插入时机(Type A专用):**
```
第2章(1400字): 插1段往事(丈夫提醒,400字)
第3章(1600字): 插2段往事(买房辛苦+温情,各300字)
第4章(1700字): 插2段往事(3年委屈回顾,各350字)
```

**委屈性质递进顺序（Type A专用，按章推进）：**
```
第2章：第1层 被纠正（尴尬，习惯不好）
第3章：第2层 被当空气（压抑，自我收缩）
第3章：第3层 被当成造成困境的人（心疼他人，主动让步）
第4章：第4层 被正式宣告是外人（透彻了，看清了）
```
每层递进的是"性质"，不是"大小"。每层后主角的情绪也要跟着变。

**往事功能分配（Type A专用，写前确认功能）：**
```
第2章往事：验证型 → 丈夫/长辈当年的提醒，现在被验证
第3章往事：证据型 → 具体数字/付出记录，证明我没做错
第4章往事：累积型 → 这不是今天一次，是年复一年
第5章往事：底气型 → 经历过的最深的伤，解释现在不退让
```
往事内容必须匹配功能，具体写法见 scene-templates.md。

**检查点:**
- [ ] 每章委屈是否递进到下一层性质（不是重复同一层）
- [ ] 每段往事插入前确认功能类型
- [ ] 往事不连续超500字
- [ ] 无重复性描写(类似委屈不超2次)

**禁止:**
- ❌ 过度内心独白(单次<50字)
- ❌ "时间一天天过去"类空话
- ❌ 重复相同句式(如连续5句"我XX")

### 第5阶段: 觉醒决策(1400字)

**每700字配方:**
```
前700字: 冷静规划
├─ 找律师场景(400字,必详)
│   ├─ 对话: 律师的点醒
│   ├─ 主角觉醒金句
│   └─ 决定行动
└─ 查资料/准备(300字,必详)

后700字: 内心确定
├─ 丈夫往事回忆(300字)
├─ "我怕我老了没路"(金句)
└─ 行动开始(200字)
```

**检查点:**
- [ ] 有专业人士点醒(律师/银行/地政)
- [ ] 有主角觉醒金句(不超20字)
- [ ] 决策过程冷静(无情绪化)

---

### 第6-7阶段: 执行反击(3300字)

**每1100字配方:**
```
行动场景(600字,必详):
├─ 卖房流程(签约/过户)
├─ 物品细节(合约/章/笔)
├─ 动作描写(手抖/停顿)
└─ 内心独白(松一口气)

冲突爆发(400字,必详):
├─ 对方震惊反应
├─ 摊牌对话(证据对质)
└─ 冷静态度("不是讨论,是通知")

过渡(100字,必简):
└─ "隔天""那天晚上"
```

**摊牌场景必备:**
- 物证展示(转账截图/合约/录音)
- 对方脸色变化(白了/愣住/手抖)
- 主角冷静态度(声音平/不争吵)
- 金句("不谈情绪,谈事实")

**检查点:**
- [ ] 反击有具体行动(卖房/签约/报警)
- [ ] 对方反应具象(非"他很震惊")
- [ ] 对话简洁有力(<15字/句)
- [ ] 主角不失控(冷静>情绪)

---

### 第8阶段: 独立收尾(800字)

**配方:**
```
新生活场景(400字,必详):
├─ 搬新房/还清债/独自生活
├─ 具体细节(杯子/窗外/阳台)
└─ 内心释然("终于松口气")

金句+收尾(200字,必详):
├─ 1句顿悟金句(不超20字)
├─ 场景画面(泡茶/看窗外)
└─ 不说教

互动引导(200字,固定格式):
└─ "谢谢你听到这里..."
```

**禁止:**
- ❌ 说教("老年人要坚强...")
- ❌ 完美结局(儿子跪地道歉)
- ❌ 过度煽情

## 📊 Type B: 平静-揭秘-真相-和解 节奏配方

### 第1-2阶段: 平静开场(2000字)

**每1000字配方:**
```
日常场景(600字,必详):
├─ 病重住院/日常相处
├─ 冷漠状态铺垫
└─ 细节: 丈夫的沉默/距离感

关系铺垫(300字,必详):
├─ 40年冷漠
└─ 女儿视角

过渡(100字,必简)
```

**Type B揭秘的3层结构（必须按层推进，不能跳级）：**
```
第1层：表面异常 → 行为反常，读者和主角都不知道原因
第2层：往事浮现 → 集中式大段往事（800-1200字），藏伏笔
第3层：真相揭晓 → 被逼出来，而非主动说；揭晓后往事被重新理解
```

**Type B往事与Type A的根本区别：**
```
Type A往事：穿插式，每段300-500字，有功能（验证/证据/累积/底气）
Type B往事：集中式，一次800-1200字连续，目的是为真相铺垫伏笔
```

**Type B真相揭晓的写法（不能直接说）：**
```
不是对方主动坦白
而是：主角问问题 → 对方回避 → 主角从回避中看出答案
或：第三方（护士/孩子/文件）触发揭晓
```

**检查点:**
- [ ] 开场不能太快进入冲突
- [ ] 往事集中在第3-5章（不穿插）
- [ ] 每个往事场景藏了一个伏笔
- [ ] 真相揭晓是被逼出来，不是主动说

---

### 第3-5阶段: 逐层揭秘(5200字)⭐核心

**每1000字配方:**
```
秘密线索(400字,必详):
├─ 第1层: 表面异常(护士一句话)
├─ 第2层: 反应异常(丈夫脸色变)
└─ 第3层: 接近真相(女儿追问)

往事回忆(400字,必详,集中式):
├─ 第4章: 年轻时相识(800字连续)
└─ 第5章: 怀孕+冷漠开始(800字连续)

悬念递进(200字,必详):
├─ "为什么会这样"
└─ 引向下一层
```

**与Type A不同:**
- 往事可超500字(集中回忆)
- 不频繁穿插
- 为真相铺垫

### 第6-7阶段: 真相大白(3200字)⭐情绪高潮

**每1600字配方:**
```
真相揭开(1000字,必详):
├─ 坦白场景(600字)
│   ├─ 对话: 一句句说出真相
│   ├─ 身体反应: 手抖/水杯掉/下跪
│   └─ 原因解释: "怕被笑/怕家散"
└─ 情绪爆发(400字)
    ├─ 女儿崩溃("只有一个爸")
    └─ 拥抱/释放

内心释然(600字,必详):
├─ 主角道歉
├─ 对方: "不用讲了"
└─ 关系重构
```

**检查点:**
- [ ] 真相一句句说清楚(非笼统"他坦白了")
- [ ] 有崩溃动作(水杯/下跪/拥抱)
- [ ] 情绪高但不失控

## 📊 Type C: 冲突-压抑-爆发-独立 节奏配方

### 第1阶段: 冲突开场(1150字)

**配方:**
```
强冲突(600字,必详):
├─ 儿子邀请回家过年
├─ 主角当场拒绝
└─ 对话尖锐(无铺垫)

背景简述(300字,必简):
├─ 离婚32年
└─ 儿子从不联系

内心波动(250字,必详):
└─ 想见vs怕伤
```

**检查点:**
- [ ] 开头就是矛盾(非悬念)
- [ ] 对话直接尖锐
- [ ] 无往事回忆

---

### 第2-5阶段: 压抑积累(5750字)⭐核心

**每1000字配方(不用往事,用当下):**
```
独自生活细节(500字,必详):
├─ 一个人吃饭(碗筷/份量)
├─ 看电视(无声/不看内容)
├─ 手机不响(等待/失望)
└─ 日常物品(老照片/空房间)

心理斗争(300字,必详):
├─ 想打电话/手指停住
├─ 买菜时想起
└─ 夜里醒来听声音

邻居/外人视角(200字,必详):
├─ 邻居劝说
└─ 主角拒绝
```

**Type C压抑的7层递进（每1000字推进1-2层，感官不重复）：**
```
第1层：听觉触发 → 对话/声音（主角假装没听到）
第2层：嗅觉侵入 → 香水/食物（无法回避，被迫感知）
第3层：视觉冲击 → 物品被改变/场景变化（具体的失去）
第4层：对话直接刺激 → 当着主角面说，不在乎被听见
第5层：经济/权力侵占 → 从精神到物质的升级
贯穿：主角"暗中记录"的内心话 → 体现主动性
中段60%：一个"小触发"让对方第一次感到恐惧
```

**Type C主角的暗中主动性（压抑阶段必须体现）：**
```
Type C不是在忍，是在主动选择观察
每一个"弛"的内心话，体现的是主角的判断力：
→ "我知道，还没到时候"
→ "让他们继续放肆"
→ "我要他们以为我什么都不知道"
禁止写成纯粹被动承受的受害者
```

**检查点:**
- [ ] 压抑段的感官是否在换（不重复同一层）
- [ ] 每1-2个压抑段后，是否有主角主动性的"弛"
- [ ] 60%处是否有一个"小触发"
- [ ] 主角有没有一句清晰的暗中意图
- [ ] 无往事穿插

## 🎯 通用检查清单(所有类型)

### 每章写完检查
- [ ] 这1000字有具体场景?
- [ ] 有身体反应/动作细节?
- [ ] 对话真实(老年人语气)?
- [ ] 情绪克制(无"心如刀绞")?
- [ ] 无啰嗦过渡句?
- [ ] 符合类型节奏(A往事/B集中/C压抑)?

### 每阶段检查
- [ ] 必详写的场景是否详写(300-500字)?
- [ ] 必简写的过渡是否简写(<150字)?
- [ ] 字数是否超标?
- [ ] 情绪密度是否适当(不过载/不空洞)?

# 通用写作技术
## 所有类型必须遵守，区分逻辑见各专属文件

---

## 一、开场设计

### 反常等式（必须在前200字完成）
```
[主角身份/付出底色] + [对方反常举动] + [主角反应] + [悬念钩子]
```

**主角底色（前250字必须出现一句）：**
让后续反击有说服力，否则主角显弱
- 职业背书："我年轻时当过主管"
- 付出量化："每天五点半起床，把地拖到发亮"
- 性格定位："我一向不爱吵，只信证据和人的反应"
- 原则宣告："我一直以为只要我肯付出"

**悬念钩子格式（开场结尾）：**
- ✅ "接下来发生的是连我自己都没想到的"
- ✅ "她错了"（暗示反转）
- ✅ "如果你想听，我就继续讲下去"
- ❌ "后来我赢了"（结果钩子，失去悬念）

## 二、心理描写

### 三禁止
- ❌ 直接说情绪："我很难过/委屈/愤怒"
- ❌ 反问式独白："他为什么这样对我？"（显弱）
- ❌ 连续超3句纯内心（读者会跳过）

### 六种有效格式
```
① 判断式："我突然明白了，[判断内容]"
② 对比式："他不是[表面原因]，他是[真正原因]"
③ 记录式："我在心里把这一条记下来"
④ 底线式："这口气我认了。但[底线]"
⑤ 确认式："就是这一句，我想清楚了"
⑥ 倒计时式："好。让他们再放肆一段时间"
```

内心独白功能：推进认知或决定，不是抒情。单次不超3句，每句不超20字。

---

## 三、对话后落地动作（通用硬规则）

重要对话 = 对话（≤15字）+ 具体动作（≤20字）
```
✅ "不是讨论，是通知" → 我把手机放回去
✅ "先吃饭" → 他低头把饭盒打开，去了一口菜
✅ "好" → 他点了一下头，像把一口气图出来
❌ 说完就写下一件事（对话漂浮，没有重量）
```

---

## 四、段落衔接（5种方式，必选其一）

```
① 动作桥：用动作切换场景，不用"然后/接着"
   "我把杯子放下，走到窗边"

② 时间压缩：半句话跳时间，后面立刻进具体场景
   "就这样过了三年"

③ 情绪落地：一句简短话/动作结束上段
   "我只回了一个字：好"

④ 内心预告：不超一句，引发下段紧张
   "我知道，真正的麻烦要来了"

⑤ 感官转换：用环境变化暗示时间
   "外面开始有人走动，天快亮了"
```

**绝对禁止：**
- ❌ "说到这里，我想起了..."
- ❌ "时间一天天过去，转眼..."
- ❌ 超50字的纯感想段落当过渡

## 五、金句设计

**4个出现时机：** 开场钩子 / 觉醒时刻 / 摊牌顶点 / 收尾定调

**5种有效格式：**
- 对比翻转："外面多体面，家里多随便"
- 事实替代情绪："不是讨论，是通知"
- 定性："你要的不是亲情，你要的是钱"
- 倒置："丢脸的是你，不是我"
- 底线宣告："不是想通了，是被逼到不得不行"

**禁止：** 超过15字 / 哲学感慨 / 一篇超过8个金句

## 六、节奏控制

**短句（3-8字）用于：** 情绪爆发前后 / 摊牌关键时刻 / 压抑的内心话 / 收尾定调句

**长句（20字以上）用于：** 往事场景铺陈 / 心理分析 / 场景建立

**全篇变化规律：**
```
铺垫段 → 长句为主
委屈/压抑段 → 中等句，情绪克制
觉醒转折 → 一句超短句打断
摊牌段 → 短句密集，快节奏
收尾段 → 长短交替
```

---

## 七、对方角色写法

**反派公式：** 外表体面 + 行为刻薄（反差制造张力）
- 必须有动机：要面子 / 要钱 / 习惯了主角让步
- 必须有破绽：某个时刻脸色变了 / 眼神闪了 / 话卡住了

**软弱角色（懦弱非坏）：** 说话前吞口水 / 眼神飘向别处 / 压低声音
- 禁止把懦弱角色写成单纯坏人

---

## 八、收尾感官定格（每篇必须有）

**格式：一个感官细节 + 主角对它的新解读**
```
✅ "冷风打在脸上。我第一次觉得那空气不是冷，是自由的味道。"
✅ "窗外阳光照进来，照在老城区灰灰的楼墙上。那光不华丽，但很实在。"
❌ "我终于明白了，人生最重要的是..." （说教式，禁止）
```

---

## 九、真实感的5个来源

1. **不完美的主角：** 会犹豫、后悔、说最没用的话
2. **具体到可核实的细节：** 金额/日期/时间/地点精确
3. **对方不是纯粹坏人：** 有自己的逻辑和恐惧
4. **意外可以推进故事：** 主角判断也有失误
5. **结局不完美：** "可以一起吃饭"比"跪地道歉"真实

---

## 十、互动引导（全篇只2次，格式固定）

```
第1次（第200字后）："如果你想听，我就继续讲下去，也请轻轻点个赞，让我知道你还在听"
第2次（结尾3行）："谢谢你听到这里，欢迎在留言区说说你的想法，我会慢慢看"
```

禁止：中间插互动 / 超过2次 / 用问句互动

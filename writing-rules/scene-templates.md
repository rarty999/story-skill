# 场景写法公式
## 公式教结构，变量槽给方向，AI自己填内容
## 每次执行必须换新的具体内容，不得照搬示例中的句子

---

## 场景1：压抑场景（⚠️ 三种类型写法完全不同）

### Type A压抑：付出被忽视型（约200字/次）
**核心感：我做了很多，被当成没做**

公式：
```
① 量化付出的细节（1-2句）
   → 具体数字或行为：几点起/做了什么/多少次
   → 不评价，只陈述事实

② 对比触发（1-2句）
   → 邻居子女的对待 / 外人的眼光 / 金额对比
   → 外部对比让差距自己说话

③ 主角克制反应（1-2句）
   → 身体先反应：喉咙/手指/脚
   → 然后压住，继续做事

④ 内心一句（1句）
   → 不是感慨，是判断或记录
   → "他不是XX，他是XX"
```

变量槽：
```
付出细节：[五点半起床/拖地到发亮][三十天带孙/没拿一分]
          [十年做同样的事][记账记了几十本]
对比触发：[邻居收礼][截图里的金额][外人的眼神]
身体反应：[喉咙发紧][手指停住][脚软一下][手心出汗]
```

---

### Type C压抑：本来就是这样型（约200字/次）
**核心感：这32年一直如此，早就知道了**

公式：
```
① 触发动作（1-2句）
   → 一个当下具体行为，暗示"原本有人/现在没人"
   → 不说"孤独"，让行为说话

② 感官填充（2-3句）
   → 选声音/温度/光线/气味其中一个展开
   → 外部越热闹，内心越冷 / 外部越安静，内心越乱

③ 行动代替情绪（1-2句）
   → 做一件小事：擦桌/数钱/记账/喝水
   → 永远不说"我很难过/孤独"
   → 用"继续做"代替"停下来哭"

④ 内心只一句（1句，≤15字）
   → 是判断，不是感慨
   → "安静是好的" / "一个人刚好"
```

**⚠️ Type C压抑禁止：**
- ❌ 与任何"以前温情时光"对比（对比只会让主角更弱）
- ❌ 说"我等他回来""我希望他打电话"（主角是主动选择的，不是被动等待）
- ❌ 连续3句都写内心感受

变量槽：
```
触发动作：[摆碗筷后收走一副][买菜数了两份又放回]
          [洗两个杯子又放回一个][把药分好又推回去]
感官选项：[楼下喊过年好/鞭炮] ← 热闹对比冷
          [水声/时钟/风扇] ← 安静填满
          [消毒水味/油烟味] ← 嗅觉
行动替情绪：[继续记账][把菜热两遍][把桌擦三遍]
内心一句：["安静是好的"]["一个人刚好"]["刚好够用"]
```

### Type B压抑：被隐瞒型（约200字/次）
**核心感：某件事不对，但不知道是什么**

公式：
```
① 异常信号（1-2句）
   → 对方的脸色/手抖/回避眼神
   → 说话不完整/停在一半

② 主角的疑惑（1-2句）
   → 不是愤怒，是"为什么"
   → 主角在观察，不是在等待答案

③ 压住疑惑继续（1-2句）
   → 假装没注意，继续正常
   → 实际在暗中观察

④ 内心一句（1句）
   → "又一次了" / "他在躲什么"
   → 悬念维持，不给答案
```

**⚠️ Type B压抑禁止：**
- ❌ 主角直接猜到真相（悬念必须维持到揭晓时刻）
- ❌ 主角问出来（假装不知道是策略）

变量槽：
```
异常信号：[脸色白了一下][话说到一半停住][眼神飘开]
          [接电话走出去][拿东西的手顿了顿]
疑惑内心：["又是这样"]["他在躲什么"]["不是第一次了"]
```

---

### 压抑场景的通用张弛节奏（三种类型共用）

**每1-2个压抑段之后，必须有一个"弛"的内心话：**
```
不是"我忍着"
而是主角在暗中积累的主动性：

Type A的弛："我把这一笔记下来"
Type C的弛："我选择的，不是被迫的"
Type B的弛："我在等，等他们放松警惕"
```

**压抑阶段中段（约60%处），必须有一个"小触发"：**
```
→ 主角一个不经意的动作/一句话
→ 让对方第一次感到意外或恐惧
→ 告诉读者：反转快了
→ 防止读者在最长的压抑段失去耐心

示例：东西倒在地上，声音不大，客厅那边瞬间安静了
      主角平静接了一个不该来的电话，对方语气变了
```

## 场景2：委屈积累（Type A核心，约400字/次）

### ⚠️ 关键：递进的是"性质"，不是"大小"

**四层性质递进（同篇内按顺序推进）：**
```
第1层：被纠正（你习惯不好）
  → 情绪：尴尬，不是愤怒
  → 写法：主角愣了一下，然后接受

第2层：被当空气（你需要被管理）
  → 情绪：压抑，开始窒息感
  → 写法：主角自我收缩（走路轻/说话少）

第3层：被当成"造成困境的人"
  → 情绪：心疼他人（怕女儿/怕儿子夹在中间）
  → 写法：主角主动让步，但为别人而非被迫

第4层：被正式宣告是外人
  → 情绪：透彻了，不是愤怒
  → 写法："终于看清了"的内心一句
```

### 公式（5步，每次写当前所在层次）

```
① 事件发生（80字）
   → 一件具体的小事
   → 只写事实，不加评价

② 第一反应-克制（30字）
   → 身体先反应：喉咙/手指/脚/心脏
   → 主角不爆发，先压住

③ 外部细节放大（60字）
   → 对方的动作/表情/语气细节
   → 越具体越有力：声音大小/眼神方向

④ 内心分析（80字）
   → 主角是明白人，看清对方动机
   → 金句格式："他不是XX，他是XX"

⑤ 压下去继续（50字）
   → 选择暂时不动
   → 行动暗示：在积累，在等
```

变量槽：
```
事件类型（按层次选）：
第1层：[被纠正油盐/被拦下碗]
第2层：[走路轻关门慢/洗衣被分开]
第3层：[半夜听到夫妻吵架/被说"习惯很…"]
第4层：[退钱+别来了/被当外人的具体一刻]

身体反应（每次换）：
[喉咙紧][手指停住][脚软][心脏撞][手心出汗][耳朵嗡]

压下去的动作：
[放下杯子/筷子][继续吃][转身][拿手机又放下]
```

## 场景3：往事回忆（⚠️ 功能决定内容）

### 四种功能，写之前先确认这段往事是做什么用的

```
① 验证型：丈夫当年说过的话，现在现实验证了
  → 内容必须有一句当年的"提醒话"
  → 格式："他那时说过XX，我那时不信，现在懂了"

② 证据型：证明主角的付出是真实的，没有做错
  → 内容必须有具体数字或行动
  → 格式：账本/记录/具体时间地点金额

③ 累积型：告诉读者"这不是今天一次的事"
  → 内容是多个相似事件的压缩
  → 格式："第一年/第二年/第三年"列举

④ 底气型：解释主角为什么现在有勇气不退让
  → 内容是主角经历过最深的伤
  → 格式：经历→当时的选择→现在的理解
```

### 公式（4步，约350字/次）

```
① 切入钩子（20字）
   → 当下某个细节触发记忆
   → 格式："[物品/动作/声音]，我想起了[时间]"

② 往事场景（200字）
   → 具体年份/地点/当时状态
   → 一个完整的小场景，不是摘要
   → 内容匹配往事功能（见上方四种）

③ 转折对比（80字）
   → "那时以为[A]，现在才知道[B]"
   → 不说"我很后悔"，说"我才懂"

④ 切回当下（50字）
   → 用一个动作回到现实
   → 格式："我把[物品]放回去" / "我抬头"
```

变量槽：
```
切入触发物：
[丈夫字条/记账本/老照片/房产证/旧药盒/老鞋]

往事场景类型（按功能选）：
验证型：[丈夫当年的提醒/父母当年说的话]
证据型：[买房省钱辛苦的具体过程/带孙记录]
累积型：[年复一年的等待/一次次的让步]
底气型：[离开时被拿走的那个/最深的一次伤]

切回动作：[把东西放回抽屉][站起来][喝一口茶][走出去]
```

**Type B往事特别说明：**
```
Type B不用穿插式往事，用集中式（一次800-1200字连续）
功能：为真相铺垫伏笔，不是证明主角有多苦
内容：每个往事场景里藏一个"现在才能看懂的伏笔"
```

## 场景4：摊牌（Type A爆发核心，约800字）

公式（7步）：
```
① 对方上门（80字）
   → 描写来者状态：脸色/表情/携带物品
   → 主角内心只一句："来了"

② 主角冷静准备（60字）
   → 一个慢动作：吸气/站起来/开门
   → 想到一句过往经验，暗示早有准备

③ 主角先发制人（120字）
   → 主角先开口，不等对方
   → 讲事实，不讲情绪
   → 格式："[数字/事件] 第一，[数字/事件] 第二"
   → 结尾金句："不是讨论，是通知"

④ 对方第一波反扑（100字）
   → 对方用情绪/道德压人，示弱或指责
   → 主角不接话，或只接一句

⑤ 物证出手（150字）⭐高潮
   → 拿出具体证据：截图/合约/账本/录音
   → 问一个对方无法回答的问题
   → 对方：脸色变/嘴张/眼神躲

⑥ 金句打击（120字）
   → 一句话点破对方本质
   → 格式："你不是[表面]，你是[本质]"

⑦ 坚定驱赶（100字）
   → 主角站起/走到门口
   → 关门，声音很轻
```

变量槽：
```
物证类型：[转账截图/房产证/合约/录音/账本/借款字条]
无法回答的问题："你敢不敢[公开]？""[那时]你在哪里？"
金句格式："你不是XX，你是XX""外面XX，家里XX"
```

## 场景5：觉醒（Type A转折，约600字）

公式（4步）：
```
① 触发物/触发对话（100字）
   → 翻出记账本 / 专业人士一句话

② 专业人士点醒（200字）
   → 律师/银行/地政/老邻居
   → 不煽情，直接给方向
   → 关键格式："要赢就别讲情绪，只讲规则"

③ 主角内心确认（150字）
   → 想起往事中某人的话
   → 当时不信→现在验证

④ 决定行动（100字）
   → 果断动作，不犹豫不哭
   → 不是复仇，是自立
```

变量槽：
```
触发物：[丈夫字条]["留条路给自己"][记账本最后一页]
专业人士：[律师-同事女儿][银行-以前学生][地政-认识的人]
觉醒金句方向：
  自立："我怕我老了没路"
  清算："该算的开始算"
  尊严："不是钱的问题，是心寒"
```

## 执行说明

### 写每个场景前确认：
1. 这是哪个类型的哪种场景？
2. 压抑场景：Type A/B/C？当前在哪一层？
3. 委屈场景：当前写的是第几层性质？
4. 往事场景：这段往事的功能是什么？
5. 对照变量槽选内容（不照搬示例句子）

### 同篇防重复规则：
- 同一变量槽选项，同篇只用一次
- 同类身体反应，同篇不超2次
- 同类触发动作，同篇不超2次

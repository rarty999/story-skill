# 3种叙事类型系统

**作用:** AI根据用户题材自动判断用哪种类型

---

## 🔍 快速判断规则

### 判断逻辑
```
有"隐藏多年的秘密"(血型/身世/牺牲) → Type B揭秘型
有"长期付出+突然背叛"(带孙/财产/偏心) → Type A往事型 ⭐默认
有"直接冲突+当下压抑"(邀请被拒/冷战) → Type C压抑型
```

### 题材对应表

| 类型 | 适合题材 | 不适合 |
|------|---------|-------|
| A往事型 | 带孙被弃/财产纠纷/偏心对待/长期付出 | 秘密揭开 |
| B揭秘型 | 血型/身世/隐瞒牺牲/误解多年 | 财产争夺 |
| C压抑型 | 离婚多年/长期疏离/冷战拒绝 | 需回忆往事 |

## 📊 Type A: 悬念-往事-爆发-收尾 (60-70%文案使用)⭐

### 识别特征
- 开头有强悬念(数字冲突/被赶/被拒)
- 需大量往事铺垫委屈
- 有长期付出记录
- 反击方式: 冷静清算(卖房/断联/证据)

### 字数配方(11500字标准)

| 阶段 | 占比 | 字数 | 内容 | 节奏 |
|------|------|------|------|------|
| 开场悬念 | 8% | 900 | 核心冲突+互动引导 | 快 |
| 往事铺垫 | 55% | 6300 | 6-8个委屈场景+5段往事 | 慢⭐ |
| 觉醒决策 | 12% | 1400 | 找律师/查资料/规划 | 平 |
| 执行反击 | 18% | 2100 | 卖房/摊牌/证据 | 急 |
| 独立收尾 | 7% | 800 | 新生活+金句 | 缓 |

### 8章分配

| 章节 | 精准字数 | 硬上限 | 内容 |
|------|---------|--------|------|
| 第1章 | 900 | 950 | 悬念开场(8.8 vs 8万8) |
| 第2章 | 1400 | 1450 | 委屈积累1+往事1 |
| 第3章 | 1600 | 1650 | 委屈积累2+往事2-3 |
| 第4章 | 1700 | 1750 | 委屈积累3+往事4-5 |
| 第5章 | 1400 | 1450 | 觉醒决策(找律师/查资料) |
| 第6章 | 1800 | 1850 | 执行反击前段(卖房/签约) |
| 第7章 | 1500 | 1550 | 执行反击后段(摊牌/证据) |
| 第8章 | 800 | 850 | 独立收尾(新生活) |
| **总计** | **11100** | **11700** | |

### 往事插入规则⭐核心

**频率:** 每1200字插1段往事
**长度:** 单次300-500字
**穿插比例:** 往事40% : 当下60%

**插入位置:**
```
第2章: 1段往事(丈夫的提醒)
第3章: 2段往事(买房辛苦+过往温情)
第4章: 2段往事(3年委屈事件回顾)
第5章后: 不再插往事
```

**往事类型:**
1. 付出型: 买房/带孙/持家辛苦
2. 温情型: 年轻时的好/丈夫的关心
3. 委屈型: 第1次心寒/第2次失望
4. 心寒型: 对比场景/关键转折点
5. 觉醒型: 丈夫警告/邻居提醒

**禁止:**
- ❌ 往事连续超过500字
- ❌ 在爆发阶段插往事
- ❌ 往事太久远(超30年)

### 关键场景必备

**6-8个委屈场景(当下):**
- 场景1: 触发事件(8.8红包/被叫搬走)
- 场景2: 视觉冲击(看到截图/空房间)
- 场景3: 声音对比(电话敷衍vs对别人热情)
- 场景4: 邻居/外人对比
- 场景5: 物品发现(记账本/合约)
- 场景6-8: 近期委屈事件回顾

**反击场景:**
- 找律师(专业人士点醒)
- 去银行/地政所(依法维权)
- 签约场景(物品细节)
- 冷静摊牌(证据对质)

### 对话库(Type A专用)

**隐忍阶段:**
- "你忙就忙,别惦记我"
- "算了,都是一家人"
- "他忙了,有心就好"

**觉醒阶段:**
- "不是钱的问题,是心寒"
- "不是他忙,是他选择"
- "我怕我老了没路"

**反击阶段:**
- "不谈情绪,谈事实"
- "照规矩走"
- "不是讨论,是通知"

## 📊 Type B: 平静-揭秘-真相-和解 (20-30%文案使用)

### 识别特征
- 开头相对平静(日常场景)
- 有隐藏多年的秘密
- 秘密层层揭开(非主角主动调查)
- 结局: 温情和解

### 字数配方(11500字标准)

| 阶段 | 占比 | 字数 | 内容 | 节奏 |
|------|------|------|------|------|
| 平静开场 | 18% | 2000 | 日常场景+冷漠状态 | 平 |
| 逐层揭秘 | 45% | 5200 | 3层秘密递进+往事回忆 | 缓→ |
| 真相大白 | 28% | 3200 | 情绪高潮+崩溃+坦白 | 急⭐ |
| 温情和解 | 9% | 1100 | 不复婚但照应 | 暖 |

### 8章分配

| 章节 | 精准字数 | 硬上限 | 内容 |
|------|---------|--------|------|
| 第1章 | 1200 | 1250 | 平静开场(病重/日常) |
| 第2章 | 800 | 850 | 冷漠状态铺垫 |
| 第3章 | 1500 | 1550 | 第1层秘密(怀疑) |
| 第4章 | 1700 | 1750 | 第2层秘密(确认)+往事1 |
| 第5章 | 2000 | 2050 | 第3层接近真相+往事2 |
| 第6章 | 1600 | 1650 | 真相揭开前段(铺垫) |
| 第7章 | 1600 | 1650 | 真相大白(崩溃坦白) |
| 第8章 | 1100 | 1150 | 温情和解 |
| **总计** | **11500** | **12000** | |

### 秘密设计3层法⭐核心

**第1层: 表面异常(让主角/读者怀疑)**
- 护士: "这血型很罕见"
- 邻居: "你姑姑身上有伤"
- 发现: 账单数字不对

**第2层: 间接证据(确认异常)**
- 丈夫反应异常(脸色变/手抖)
- 银行流水指向赌场
- 监控拍到可疑画面

**第3层: 真相即将揭开(悬念拉满)**
- 女儿追问
- 再次意外触发
- 压力下崩溃前夕

**真相揭开(情绪高潮):**
- 坦白: 孟买血型/自己不能生/隐瞒原因
- 崩溃: 手抖/水杯掉/下跪
- 释放: "只有一个爸"/拥抱

### 往事回忆规则(与Type A不同)

**集中式回忆(非穿插):**
- 第4章: 集中回忆年轻时相识(800-1000字)
- 第5章: 集中回忆怀孕+冷漠开始(800-1000字)
- 其他章: 不插往事

**特点:**
- 往事较连贯,可超500字
- 集中在揭秘中段
- 为真相铺垫

### 对话库(Type B专用)

**平静阶段:**
- "手术很成功,好好养"
- "没事,我照顾就好"

**怀疑阶段:**
- "护士说我血型很罕见"
- "你怎么了?脸色不太对"

**真相阶段:**
- "我其实本来就不能生"
- "怕被笑,怕没面子,我不敢讲"
- "所以我这辈子只有一个爸"

**和解阶段:**
- "不用讲了"
- "以后好好过"
- "比复婚更重"

## 📊 Type C: 冲突-压抑-爆发-独立 (10-20%文案使用)

### 识别特征
- 开头就是强冲突(非悬念,是矛盾)
- 几乎无往事回忆
- 当下压抑感极强
- 反击方式: 果断拒绝+划清边界

### 字数配方(11500字标准)

| 阶段 | 占比 | 字数 | 内容 | 节奏 |
|------|------|------|------|------|
| 冲突开场 | 10% | 1150 | 强冲突(邀请/要求) | 快 |
| 压抑积累 | 50% | 5750 | 当下煎熬+心理斗争 | 压⭐ |
| 突然爆发 | 23% | 2650 | 果断拒绝+无犹豫 | 急 |
| 坚定收尾 | 17% | 1950 | 独立生活+划界 | 稳 |

### 8章分配

| 章节 | 精准字数 | 硬上限 | 内容 |
|------|---------|--------|------|
| 第1章 | 1150 | 1200 | 冲突开场 |
| 第2章 | 1300 | 1350 | 压抑1(独自生活) |
| 第3章 | 1450 | 1500 | 压抑2(心理斗争) |
| 第4章 | 1500 | 1550 | 压抑3(邻居劝说) |
| 第5章 | 1500 | 1550 | 压抑4(想见vs怕伤) |
| 第6章 | 1400 | 1450 | 决定拒绝(内心确定) |
| 第7章 | 1250 | 1300 | 果断爆发(电话拒绝) |
| 第8章 | 1950 | 2000 | 坚定收尾 |
| **总计** | **11500** | **12000** | |

### 压抑描写技巧⭐核心(不用往事)

**用当下细节代替往事:**
- 一个人吃饭(碗筷摆法/饭菜份量)
- 看电视(无声/不看内容)
- 邻居关心(对比/点醒)
- 手机不响(等待/失望)
- 日常物品(老照片/空房间/单人床)

**心理斗争描写:**
- "想打电话/手指停住"
- "买菜时看到XX,想起XX"
- "夜里醒来/听见楼下声音以为是XX"

**禁止:**
- ❌ 插入往事回忆
- ❌ 过度煽情
- ❌ 犹豫不决(必须果断)

### 对话库(Type C专用)

**冲突阶段:**
- "回去过年" - "去找你后妈"
- "妈你别这样" - "我没有这样"

**压抑阶段:**
- (几乎无对话,独自压抑)
- 邻居: "要不要打给他"
- 主角: "不用了"

**爆发阶段:**
- "我不需要你的怜悯"
- "这么多年你没想过我,现在也不用想"
- "不是想通,是被逼到不得不行"

**收尾阶段:**
- "一个人住,刚刚好"
- "我第一次不用看任何人脸色"

## 🔧 使用方法

### Phase0阶段
AI根据用户提供的题材,自动判断:
```
用户: "母亲节儿子给我8.8,给岳母8万8"
→ 判断: Type A(有数字冲突+长期付出)
→ 输出: "本文使用Type A: 悬念-往事-爆发-收尾"
```

### Phase1阶段
根据判断的类型,调用对应的字数配方:
```
Type A → 8章分配: 900/1400/1600/1700/1400/1800/1500/800
Type B → 8章分配: 1200/800/1500/1700/2000/1600/1600/1100
Type C → 8章分配: 1150/1300/1450/1500/1500/1400/1250/1950
```

### Phase2阶段
按类型执行对应的节奏控制:
```
Type A → 每1200字插1段往事,第5章后停止
Type B → 第4-5章集中回忆,其他章不插
Type C → 全程不插往事,用当下细节
```
